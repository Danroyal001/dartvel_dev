# Android app size: why 54 MB, and what it is now (15 Nov 2026)

Measured with `unzip -lv` on APKs already on the server. No builds were run.

## Short answer

1. The 54 MB files (7 Oct) were **universal** release APKs. Each one held the native code for three CPU types (armeabi-v7a, arm64-v8a, x86_64), and a phone uses only one.
2. Native code was 53.8 of the 54.3 MB: the Flutter engine (`libflutter.so`, 8.2 to 12.5 MB per ABI) plus our compiled Dart (`libapp.so`, 6.8 to 7.5 MB per ABI), stored uncompressed.
3. Debug builds, fonts and icons were not the cause. These were release AOT builds with no `kernel_blob`. Fonts came to 0.07 MB, and Material Icons were already tree-shaken (4.7 KB). Dex was 0.23 MB.
4. `dartvel build android` has `--split-per-abi` off by default, so it makes a universal APK unless you pass the flag. Per-ABI APKs from the same apps are **15.7 to 20 MB**, and an arm64 phone needs only its own 18.4 to 18.7 MB file.
5. The floor is the Flutter engine: 11.2 MB on arm64 and 8.2 MB on armv7. Our own code adds 5.8 to 7.8 MB. Further cuts have to come from packaging and from the app's own code and assets.

## Where the 54 MB went (eating_today.apk, 7 Oct, 56,599,501 bytes)

| Part | armeabi-v7a | arm64-v8a | x86_64 |
|---|---|---|---|
| libflutter.so (engine) | 8.22 MB | 11.20 MB | 12.45 MB |
| libapp.so (our Dart, AOT) | 7.50 MB | 6.75 MB | 7.00 MB |
| libdartjni.so | 0.08 MB | 0.13 MB | 0.11 MB |

Everything else (dex, flutter_assets, fonts, res) came to about 0.43 MB.

## What Dartvel can still do

- **Turn `--split-per-abi` on by default** for APK builds (`packages/dartvel_cli/lib/src/commands/build_command.dart`, currently `defaultsTo: false`). A phone then gets about 16 to 19 MB instead of 54 to 61 MB. Use `--format aab` for Play, which delivers per-ABI splits by itself.
- **Drop x86_64 from phone downloads.** It is the largest slice (19.9 to 20.2 MB) and only emulators and ChromeOS need it.
- **Compress the native libraries in sideloaded APKs.** The libraries are stored uncompressed today. Gzip of the Dev Launcher arm64 libraries gives 5.5 MB for libflutter.so (from 11.2 MB) and 2.4 MB for libapp.so (from 5.9 MB). That points to a download of roughly 8 to 9 MB for arm64, at the cost of extracting them at install. This is an estimate: no compressed APK has been built yet.
- **Already on by default:** release `--obfuscate` with `--split-debug-info=build/debug-info` (the shipped libapp.so is stripped), and `--tree-shake-icons`.
- **Per app:** keep heavy packages and assets out unless a screen needs them. In Wahala, `flutter_scene` adds about 5 MB per ABI compared with 7 Oct.
