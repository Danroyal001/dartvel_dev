Feature #3: Platform Api Access
============================================================

Summary
-------
Ship unified surface for device APIs (camera, location, sensors, secure
storage).

Key Deliverables
-----------------
1. Inventory top platform APIs required across mobile/desktop/web.
2. Select or build Flutter packages meeting licensing and maintenance standards.
3. Wrap APIs in `dartvel_platform` with consistent async error handling.
4. Document capability matrix by platform and implement fallbacks.
5. Add sample app demonstrating multi-platform usage.
